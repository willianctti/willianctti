## Selected Projects

### 🧠 [NaMosca — Computational Neural Simulation](https://github.com/willianctti/namosca)

An experimental project exploring how real biological neural connectivity can be represented and simulated computationally.

- Uses published *Drosophila* connectome datasets.
- Implements Leaky Integrate-and-Fire (LIF) neural simulations.
- Explores neural pathways and their relationship to motor systems.
- Visualizes neural activity and simulated responses.

The project distinguishes real biological connectivity data from computational assumptions and simplified visual representations.

### 📈 [Quant Lab — Machine Learning & Financial Data](https://github.com/willianctti/quant-lab)

An experimental machine learning pipeline for analyzing financial time-series data.

- Python-based data processing and feature engineering.
- Classification models using scikit-learn.
- Chronological training and evaluation.
- Backtesting and model performance visualization.
- React dashboard for exploring results.

### 🖥️ [XP-System — Browser-Based Desktop Environment](https://github.com/willianctti/windows-xp-svelte)

An interactive desktop environment inspired by Windows XP, built with Svelte and Node.js.

Features include window management, authentication, file management, interactive applications, and an integrated code editor.

### 🛠️ [SiteGen — Visual Website Builder](https://github.com/willianctti/siteGen)

A landing page generator built with Next.js and TypeScript, featuring component customization, real-time previews, and source code export.
